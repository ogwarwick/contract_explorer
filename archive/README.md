# Archive Directory

This directory contains historical prototypes, exploratory notebooks, diagnostic scripts, and research papers preserved for reference.

## Subdirectories

- **`exploratory_notebooks_and_scripts/`**: Initial parsing notebooks and scratch exploration (`OOP.ipynb`, `output.json`, `080626 parsing attempt.ipynb`, `muck_about.py`).
- **`early_prototypes_and_ui/`**: Early static HTML viewers and rendering tests (`viewer.html`, `contract_html_rendering_test.html`).
- **`legacy_search_scripts/`**: Diagnostic, FAISS-based, and intermediate embedding test scripts superseded by `search_functionality/hybrid_search.py` and PostgreSQL `pgvector`.
- **`research_papers/`**: Reference academic papers (`2504.10508v1.pdf`).
